## How to run locally (quick)
1. Install dependencies (prefer a virtualenv):
   ```bash
   python -m pip install -r requirements.txt
   ```
2. Run the converter:
   ```bash
   python scripts/convert_jsonl_to_mp3.py --input text_convert_mp3.jsonl --outdir mp3_output
   ```
3. Optional flags:
   - --lang <code>   — set TTS language (default "en")
   - --slow          — use slower speech
   - --overwrite     — overwrite existing mp3s

⚠️ Note: The script uses gTTS (Google TTS) so an internet connection is required while converting.
